# Realistic lesson illustration replacement

Work in progress: 120 of 680 lessons reviewed and converted to material raster illustrations. 560 remain. See REALISTIC_LESSON_COVERAGE.csv for the exact list. A passing runtime audit or an image count does not mean this topic review is finished.

The user's approved reference is a realistic material cutaway beside three numbered explanations in the existing ARCHIPRO UZ lesson reader. New pictures are generated with the built-in image generation tool, checked against the actual lesson and refined when misleading. Native text carries the explanations and exact exercise values. Generated illustrations are not measured drawings or engineering details. No SHNQ audit is claimed for this replacement phase; the user deferred it.

The JSON manifest lists only accepted lesson-specific pictures. It replaces the old schematic supplements for those lessons; original content blocks, quizzes, workbook actions/results, progress rules and genuine Graphisoft documentation captures remain. Unreviewed lessons keep their current figures until their replacements pass review. Prior SVGs remain in the repository for rollback. Customer pictures are loaded locally; no network request is needed.

Accepted image refinements include correcting the wall/foundation misalignment example, eliminating a spurious vertical gap in the floor-to-floor wall comparison, moving column center marks onto visible top faces, clearing colliding corridor door leaves, matching the roof across plan/facade/section/site views, and making the pedestrian path continuous.

The compressed JPEG copies retain source pixel dimensions at quality 92. Full generated PNGs are retained separately during authoring. The next imports must use explicit lesson codes, three accurate picture explanations, the existing worked stage, and the unchanged exercise/result. Do not mark a lesson accepted merely because an image exists.
